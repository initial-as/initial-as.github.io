## 2. Dasar Teori

### 2.1. Laboratorium Cybersecurity

Laboratorium Cybersecurity merupakan lingkungan terisolasi yang digunakan untuk melakukan simulasi serangan, pertahanan, monitoring, dan investigasi keamanan tanpa mempengaruhi jaringan sebenarnya. Pada mata kuliah ini, seluruh aktivitas akan dilakukan di dalam Virtual Machine.

---

### 2.2. Virtualisasi

Virtualisasi memungkinkan satu komputer menjalankan beberapa sistem operasi secara bersamaan. Keuntungan virtualisasi:

* hemat biaya
* aman
* mudah melakukan snapshot
* mudah dikembalikan ketika terjadi kesalahan

Software virtualisasi yang umum digunakan:

* Oracle VirtualBox (ini yang akan kita gunakan)
* VMware Workstation Player

## 5. Langkah Praktikum

### 5.1. Instalasi VirtualBox

1. Download VirtualBox.
2. Install dengan konfigurasi default.
3. Restart komputer jika diminta.

---

### 5.2. Membuat Host-Only Network

Buka Oracle VirtualBox, klik menu File → Tools → Network (atau gunakan tombol pintas <kbd>Ctrl</kbd> + <kbd>H</kbd>). Pada tab Host-only Networks, tambahkan jaringan:

```
192.168.56.1/24
```

Jika jaringan tersebut sudah ada, maka tidak perlu ditambahkan lagi. DHCP dapat dinonaktifkan agar konfigurasi IP dilakukan secara manual.

### 5.5. Konfigurasi Jaringan

**Konfigurasi Adapter**

| Host               | Adapter 1                 | Adapter 2 |
| ------------------ | ------------------------- | --------- |
| Ubuntu Server (VM) | NAT                       | Host-Only |
| Kali Linux (VM)    | NAT                       | Host-Only |
| Windows (Host)     | Adapter fisik ke Internet | Host-Only |

**Konfigurasi Alamat IP**

| Host          | Alamat IP (Host-Only) |
| ------------- | --------------------- |
| Windows       | 192.168.56.1          |
| Ubuntu Server | 192.168.56.10         |
| Kali          | 192.168.56.20         |

Semua host menggunakan subnet mask: ```255.255.255.0``` serta tidak memerlukan IP gateway/routes.

**Cara Konfigurasi IP**

1. Windows<br />
    Pengaturan IP untuk Windows dilakukan di *Control Panel*, gunakan IP ```192.168.56.1```.
2. Ubuntu
    - Ketik perintah ```ip a```. Kemudian cari interface adapter 2 berdasarkan MAC Address (misalnya interface enp0s8 memiliki MAC Address yang sama dengan adapter 2).
    - Gunakan nano untuk mengubah konfigurasi IP: `sudo nano /etc/netplan/00-installer-config.yaml`
    - Gunakan konfigurasi berikut, letakkan di interface yang sesuai (pada contoh di bawah digunakan interface enp0s8):
        ```yaml title="/etc/netplan/00-installer-config.yaml"
        # This is the network config written by 'subiquity'
        network:
          ethernets:
            enp0s3:
              dhcp4: true
              dhcp6: true
              match:
                macaddress: 08:00:27:2a:81:ec
              set-name: enp0s3
            // highlight-start
            enp0s8:
              dhcp4: false
              addresses:
              - 192.168.56.10/24
            // highlight-end
          version: 2
        ```
    - Lakukan validasi konfigurasi jaringan dengan perintah `sudo netplan try`, jika tidak ada error yang muncul, tekan <kbd>Enter</kbd>.
    - Ketik perintah `sudo netplan apply` untuk menerapkan konfigurasi jaringan yang telah dibuat.
    - Ketik perintah `ip a` lalu pastikan IP sudah berubah menjadi `192.168.56.10`.
3. Kali<br />
    Pengaturan IP di Kali dapat dilakukan melalui Advanced Network Configuraion yang bisa diakses dari tombol start.

1. Buatlah diagram topologi jaringan lab virtual yang digunakan dalam praktikum ini menggunakan aplikasi diagram (misalnya draw.io). Gambarkan lengkap dengan alamat IP masing-masing host.<br />**TOPOLOGINYA JANGAN DI-GENERATE DENGAN AI !!**
